# Frames de Fotografia — Empório LeleCute

Templates oficiais para padronizar **catálogo, PDP, banners e redes**. Use a mesma régua em toda foto nova.

---

## Frame A — Still-Life Editorial (4:5)
**Onde usar:** catálogo, PDP, grids, thumbnails, vitrines, feed Instagram, Pinterest.

```
┌──────────────────────────┐  4:5 (vertical)
│                          │  ex.: 1080 × 1350 px
│      [ar / luz ]         │
│                          │
│      ▓▓▓ PRODUTO ▓▓▓     │  centralizado ou levemente
│      ▓▓▓▓▓▓▓▓▓▓▓▓▓       │  deslocado p/ esquerda
│       sombra suave       │
│                          │
│   (textura sutil base)   │
└──────────────────────────┘
```

- **Fundo:** linho cru / madeira clara / pedra clara / parede off-white
- **Luz:** lateral natural difusa (janela), manhã ou tarde
- **Sombra:** suave, alongada, nunca dura
- **Margem visual:** mínimo 15% de espaço negativo em torno do produto
- **Props (máx. 2):** tecido cru dobrado, bandeja fosca, flor seca pequena
- **Câmera:** ligeiramente acima (10–20°), nunca de cima total

## Frame B — Lifestyle Silencioso (3:2 ou 16:9)
**Onde usar:** hero homepage, banners de seção, página Ateliê, stories.

```
┌────────────────────────────────────────┐  3:2 ou 16:9
│                                        │
│   [bancada / mesa / banheiro]          │
│        ▓▓▓ produto em uso              │
│   ✋ mão real (parcial)                 │
│        vela acesa . tecido . xícara    │
│                                        │
└────────────────────────────────────────┘
```

- **Cena:** rotina real — manhã, banho, mesa posta, ateliê
- **Presença humana:** mãos, ombro, perfil — nunca rosto frontal completo
- **Movimento:** pequeno (vapor, mão alcançando, derramar)
- **Cores:** creme, areia, linho, madeira; coral apenas em detalhe
- **Texto:** zona segura à esquerda ou direita (1/3 da largura) reservada para banner copy

## Frame C — Close-up de Textura (1:1) *— uso pontual*
**Onde usar:** apoio em PDP, carrosséis de detalhe, releases.

```
┌──────────────────┐  1:1
│   ▓▓▓▓▓▓▓▓▓▓▓    │
│   ▓ macro ▓▓▓    │  preencher 70–80% do frame
│   ▓ textura ▓    │  foco no relevo / grão / fibra
│   ▓▓▓▓▓▓▓▓▓▓▓    │
└──────────────────┘
```

- **Lente:** macro real ou aproximação
- **Foco:** raso, foco no detalhe artesanal (selo, costura, papel, sache)
- **Cor:** tons da paleta, nunca alto contraste

## Aspect ratios oficiais

| Uso              | Ratio  | Pixels recomendados |
|------------------|--------|---------------------|
| PDP / catálogo   | 4:5    | 1080 × 1350         |
| Hero / banner    | 16:9   | 1920 × 1080         |
| Banner seção     | 3:2    | 1500 × 1000         |
| Close-up         | 1:1    | 1080 × 1080         |
| Stories / Reels  | 9:16   | 1080 × 1920         |

## Régua de consistência (faça antes de bater)

1. A última foto bate visualmente com as 10 anteriores?
2. Mesma luz? Mesma temperatura?
3. Mesma família de fundos?
4. Mesma distância da câmera?
5. O produto ocupa proporção semelhante do frame?

Se 1 "não" → reajustar antes de bater a sequência.
